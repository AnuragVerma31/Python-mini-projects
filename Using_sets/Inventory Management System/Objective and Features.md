# Objective

The objective of this project is to design a basic Inventory Management System using Python that allows users to manage available stock, add new items, and track sold products efficiently.
The system demonstrates the use of data structures for handling real-world inventory operations.

# Features

- Add new items to inventory
- Remove or sell items from stock
- Track available items
- Maintain record of sold items
- Prevent duplicate entries using sets
- Simple menu-driven interface
