# Objective

The objective of this project is to develop a Unique Visitor Tracker using Python that records and analyzes visitor entries while identifying unique visitors.
The system uses set data structures to eliminate duplicate entries and provide accurate insights into total visits and distinct users.

# Features

- Records visitor entries
- Identifies unique visitors using sets
- Counts total number of visits
- Counts number of unique visitors
- Eliminates duplicate entries automatically
- Simple input-based tracking system
