# Objective

The objective of this project is to build a simple Email Spam Filter using Python that classifies emails as spam or non-spam based on the presence of predefined suspicious keywords.
This project introduces basic concepts of text processing and cybersecurity filtering techniques.

# Features

- Detects spam using keyword matching
- Uses set operations for fast comparison
- Identifies multiple spam words in an email
- Classifies email as Spam or Not Spam
- Displays matched suspicious words
- Simple and efficient filtering logic
