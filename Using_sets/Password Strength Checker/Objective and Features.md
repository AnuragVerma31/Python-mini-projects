# Objective

The objective of this project is to develop a Password Strength Checker using Python that evaluates the security level of a password based on predefined rules such as length, presence of uppercase and lowercase letters, digits, and special characters.
This project aims to promote better password practices and enhance user awareness regarding cybersecurity.

# Features

- Checks minimum password length
- Detects uppercase and lowercase characters
- Identifies numeric digits
- Detects special symbols
- Classifies password as Weak, Moderate, or Strong
- Provides simple and fast evaluation
